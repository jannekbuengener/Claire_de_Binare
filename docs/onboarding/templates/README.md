# Onboarding templates

Reusable templates for agent prompts, evidence docs, and PR bodies.

| Template | Purpose |
|---|---|
| [`agent_prompt_template.md`](agent_prompt_template.md) | Structured agent prompt starter |
| [`evidence_doc_template.md`](evidence_doc_template.md) | Evidence / session-log skeleton |
| [`pr_body_template.md`](pr_body_template.md) | PR body skeleton (Delivered / Validation / Non-goals) |

Templates are starting points, not SSOTs. Prefer live batch-PR marker/ledger
conventions from [`docs/runbooks/PR_ROUTING_AND_BATCH_MERGE_POLICY.md`](../../runbooks/PR_ROUTING_AND_BATCH_MERGE_POLICY.md)
when opening Batch-PRs.
